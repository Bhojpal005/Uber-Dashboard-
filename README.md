# 🚖 Uber Ride Analytics Dashboard – Power BI

## 📌 Project Headline

**Transforming Uber Ride Data into Actionable Business Insights using Microsoft Power BI**

---

## 📊 Description

An interactive **Uber Ride Analytics Dashboard** built using **Microsoft Power BI** to analyze ride bookings, revenue, trip patterns, customer behavior, and operational performance.

The dashboard converts raw ride data into meaningful visual insights to identify **peak demand periods, high-performing locations, revenue trends, and ride behavior**.

---

## 🎯 Purpose

The main objective of this project is to analyze Uber ride data and provide a clear, interactive view of business performance.

The dashboard helps stakeholders:

- Monitor overall ride and revenue performance
- Identify peak booking periods
- Analyze ride demand by time and location
- Understand customer and trip behavior
- Identify high-demand pickup locations
- Support data-driven operational decisions

---

## 🛠️ Tech Stack

- **Microsoft Power BI** – Dashboard development & visualization
- **Power Query** – Data cleaning and transformation
- **DAX** – Calculated measures and KPIs
- **Microsoft Excel** – Data source / data preparation
- **Data Modeling** – Relationships and analytical modeling

---

## 📂 Data Source

The dataset used in this project was downloaded from **Kaggle** in Excel format.

The dataset contains detailed Uber ride information, including:

- Booking Details
- Ride & Trip Information
- Pickup & Drop-off Locations
- Date & Time
- Vehicle Type
- Booking Status
- Customer Information
- Payment Details
- Fare & Revenue
- Trip Distance

The Excel dataset was imported into **Microsoft Power BI**, where it was cleaned, transformed, modeled, and analyzed using **Power Query and DAX**.

## 💡 Business Insights

### 📈 1. Demand Optimization

Identifying peak booking hours can help optimize **driver availability and fleet allocation** during high-demand periods.

### 🚗 2. Driver Allocation

High-demand pickup locations can be prioritized for better driver positioning and reduced passenger waiting time.

### 💰 3. Revenue Analysis

Revenue trends can be analyzed across different time periods and ride segments to identify stronger-performing periods.

### ⏰ 4. Peak-Hour Strategy

Understanding demand patterns by hour and day can support better **pricing, promotions, and operational planning**.

### 📍 5. Location-Based Planning

Pickup and drop-off analysis can help identify areas with consistently high ride demand.

### 📊 6. Data-Driven Decision Making

The dashboard provides a centralized view of ride performance, helping convert raw data into actionable business decisions.
